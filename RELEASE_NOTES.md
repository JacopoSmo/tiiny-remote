Download the .apk below on your phone and open it to install or update (or in the app: Settings → App updates → Update app). It installs over 4.0.0 (and 3.2) and keeps your settings and chats.

- **NAS agent from the terminal:** Automate → Connectors → NAS agent now has **How to set it up (Terminal)** beside the GitHub guide: the few commands to run over SSH from your phone (Termius, Termux…), each with a Copy button, from making the token to checking that it runs.
