## What's new: a full clean-up ("Slytherin Mode")
- **Fixed a possible crash in Activity:** two identical log lines in the same millisecond (e.g. two web searches finishing together) could crash the screen.
- **Chat:** the "NPU fault" hint now appears only when an answer broke off because the connection was lost, not for other errors such as a too-long chat.
- **Chat:** asking the model to edit a picture when the chat has none gives a clear message instead of an empty error.
- **VPN:** a second tap while the VPN is switching no longer starts a second, crossing switch.
- **Video:** progress checks read the Tiiny's answer once instead of three times.
- **Faster:** model lists and the log no longer rebuild their text patterns on every redraw.
- **About:** no longer downloads the Tiiny's whole API description just for a version number.
- **Smaller fixes:** the log screen is titled "Activity" like the menu, and model info explains the Thinking slider.
